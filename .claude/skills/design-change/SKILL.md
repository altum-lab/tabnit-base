# 설계 변경 요청: $ARGUMENTS

구현을 멈춘다. 지금 작업 중인 변경은 커밋하지 않고 둔다.

아래 양식으로 `.github/ISSUE_TEMPLATE/design-change.md` 에 맞는 본문을 만든다.

```
## 바꾸려는 것
(문서 번호와 절, 지금 적힌 내용, 바꾸려는 내용)

## 이유
(어느 작업 카드에서, 어떤 입력으로, 무엇이 안 되는가. 다시 만드는 방법)

## 영향받는 모듈과 작업
(모듈 이름, 작업 번호, 깨지는 시험)

## 대안
(설계를 안 바꾸고 할 수 있는 방법과 그 비용. 없으면 없다고 쓴다)
```

- 사람이 승인하면 `gh issue create --label 설계변경` 으로 올린다.
- 대표가 결정해 `docs/D2` 에 한 줄이 추가된 뒤에만, 해당 문서와 코드를 같은 변경에서 고친다.
- 결정을 기다리는 동안 이 카드와 무관한 다른 카드로 넘어가도 된다. 추측으로 빈 곳을 메워 구현하지 않는다.

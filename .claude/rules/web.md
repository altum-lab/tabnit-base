# 화면 코드 규칙

- 서버 호출은 OpenAPI 규격에서 만든 코드만 쓴다. 손으로 `fetch` 를 쓰지 않고, 만든 코드를 고치지 않는다.
- 화면에서 수를 다시 세거나 정렬을 바꾸지 않는다. 서버가 준 값과 순서를 그대로 보여 준다.
- 웹 표준 기능을 쓸 때는 `modern-web-guidance` 스킬의 안내를 먼저 본다. 구식 방식(불필요한 폴리필, 직접 만든 모달·툴팁)을 새로 넣지 않는다.
- 화면을 고쳤으면 `playwright` MCP 로 실제 화면을 열어 대기 상태, 오류 상태, 결과 없음 상태를 눈으로 확인한 뒤 Playwright 시험을 돌린다.
- 관계 지도처럼 노드가 많은 화면의 성능은 `chrome-devtools` MCP 의 성능 기록으로 잰다. 느낌으로 고치지 않는다.

# packs — Pack 자료

예시 Pack 둘(제조 안전, 퇴직연금)과 시험용 Pack 하나(test-mini). 형식은 D6을 따른다.

읽을 문서: D6 (형식의 기준).

## 지킬 것
- **가상 데이터만 둔다.** 고객 자료, 실제 현장 자료, 실명, 실제 설비 번호나 문서 번호를 넣지 않는다. 새 자료가 필요하면 지어낸다.
- 검증 질문의 정답은 대표가 정한다. 정답 파일을 임의로 고치지 않는다.
- Pack을 고치면 그 Pack의 검증 질문을 다시 돌린다.
- Pack 은 정의만 담는다. 개체와 관계는 입력 자료가 link 를 거쳐 들어온다. 예시 입력 파일은 Pack 의 `data/` 에 둘 수 있다.
- Pack 의 유형과 속성의 이름을 `tools/pack-terms.txt` 에 더해 일반성 검사가 엔진 코드에서 찾게 한다.
- 코드를 Pack에 맞추려고 Pack의 형식을 벗어나지 않는다. 형식이 모자라면 설계 변경 절차로 D6을 고친다.

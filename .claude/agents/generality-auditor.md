Tabnit Base 는 시연 앱이 아니라 어떤 업무 영역에도 쓰는 제품이다. 너는 엔진이 처음 보는 Pack 에도 동작하는지만 본다. 코드를 고치지 않는다.

할 일:

1. `bash tools/check-generality.sh --all` 을 돌려 결과를 읽는다.
2. 바뀐 코드에서 찾는다: 문자열 유형 이름과의 비교, 열 이름 상수, 결과 개수를 뜻하는 숫자, 특정 시나리오에서만 참인 조건, 예시 Pack 에서만 생기는 경우를 덮는 예외 처리.
3. 시험을 본다: 일반 시험(빈 입력, 경계, 큰 입력, 잘못된 입력)이 있는가. 시험 자료가 예시 Pack 의 값을 베꼈는가. 기능이 예시 Pack 하나에서만 확인됐는가.
4. `packs/test-mini` 로 같은 기능이 코드 수정 없이 도는지 관련 시험을 돌려 본다.

보고 형식: 발견마다 `파일:행 — 어떤 Pack 전제가 들어 있는가 — 다른 Pack 에서 어떻게 깨지는가 — 권하는 처리(Pack 으로 옮기기, D6 변경 요청, 일반 시험 추가)`. 없으면 "발견 없음"과 확인한 범위를 적는다.

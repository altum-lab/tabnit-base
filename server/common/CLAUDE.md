# common — 공통 (주인 자리: E)

로그인과 세션, 역할, 감사 기록, 공통 오류 형식. 다른 모든 모듈이 이 모듈에 기대므로 여기의 변경은 전체에 닿는다.

읽을 문서: D2, D9. 관련 작업: E-02, E-03, E-05, E-06.

## 맡는 것
- 로그인과 세션. 로그인하지 않으면 API와 화면을 쓸 수 없다.
- 역할 2종: 관리자(Pack 적재까지), 담당자(조치 확정까지).
- 감사 기록: 누가, 언제, 무엇을 조회하거나 바꿨는지, 결과.
- 공통 오류 형식과 오류 코드.

## 지킬 것
- 이 모듈은 다른 모듈에 의존하지 않는다. 업무 개념(관계, 조치, Pack)을 여기에 넣지 않는다.
- 감사 기록에 실패하면 그 변경 요청도 실패로 처리한다. 기록 없이 변경이 남으면 안 된다.
- 권한이 없는 요청은 거부하고 그 사실도 감사 기록에 남긴다.
- 비밀번호는 평문으로 저장하거나 기록에 남기지 않는다. 감사 기록에 개인 식별 값을 필요 이상 넣지 않는다.
- 공개 API의 모양을 바꾸면 모든 모듈이 깨진다. 바꾸기 전에 설계 변경 절차를 따른다.

## 하지 않는 것
- 조회 범위 제한과 가림 처리(A-12), 백업과 복원(E-13), 설치 매뉴얼(E-14)은 당김 범위다. 작업 카드가 있고 필수 범위가 밀리지 않을 때만 만든다 (D1 4절).
- 행내 인증 연동 준비(E-15)와 보안 점검 대응(E-16)은 1월 범위다. 만들지 않는다.
- 뼈대 단계에는 로그인과 감사 기록 없이 API 를 연다 (D2 AD-80). 로그인(E-02)과 감사 기록(E-03, E-05)이 끝나는 변경에서 이 임시 처리를 닫는다.

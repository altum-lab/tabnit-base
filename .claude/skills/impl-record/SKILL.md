# 구현 기록 정리: $ARGUMENTS

이번 변경: !`git diff --stat origin/main...HEAD`

개발 보드 "구현 기록" 화면의 기능 항목(예: CORE-03 시점 조회)에 붙여 넣을 내용을 아래 양식으로 만든다. 코드에서 확인한 사실만 적는다.

```
기능: (보드의 기능 번호와 이름)
작업: $ARGUMENTS
입력: (공개 API 의 인자. 기준 날짜가 있는지)
출력: (돌려주는 것, 정렬 기준, 근거 연결)
예외 처리: (잘못된 입력, 빈 결과, 한계 초과에서 무엇을 하는가)
미진한 내용: (안 한 것, 임시로 처리한 것. 없으면 "없음")
다음에 할 일: (작업 번호가 있으면 번호로)
코드 위치: (패키지 또는 파일)
완성도: (0~100. 근거 한 줄: 통과한 일반 시험 수, 검증 질문 수)
버전: (0.x.y. 공개 API 가 바뀌면 가운데 자리를 올린다)
```

보드는 브라우저에서 사람이 고친다. Claude 는 보드의 자료 파일을 직접 고치지 않는다. 정리한 내용을 사람에게 주고, 같은 내용을 PR 설명의 "설계와 기록"에 붙인다.
